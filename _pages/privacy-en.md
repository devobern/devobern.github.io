## Data controller

Nicolin Dora, Switzerland · <mailto:mail@nicolin-dora.ch>

## Principle

This website is static. There are no user accounts, no forms and no
advertising or profiling cookies.

## Hosting

The site is served through GitHub Pages (GitHub, Inc.). When you request a
page, the host processes technically necessary connection data such as IP
address, user agent and timestamp, among other things for security and
debugging purposes. I have no access to these server logs.

## Analytics

For basic analytics I use [GoatCounter](https://www.goatcounter.com/).
GoatCounter sets no cookies, does not store IP addresses permanently and does
not build cross-device profiles. It records aggregated information such as the
page visited, the referrer, approximate screen size and country. If your
browser sends "Do Not Track", nothing is counted; a script blocker prevents
measurement entirely.

## Comments

Comments are provided by [Giscus](https://giscus.app/) and stored in the
GitHub Discussions of this repository. The comment area is loaded as an iframe
from `giscus.app`, which means GitHub learns your IP address. You need a GitHub
account to comment, and GitHub's privacy terms apply in addition. No account is
needed if you do not interact with the comment area.

## Your rights

You have the right to access, rectification and erasure of your personal data.
Please contact <mailto:mail@nicolin-dora.ch>.
